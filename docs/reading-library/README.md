# 📚 مكتبة مصادر القراءة — جاهزة للصق في Google Sheets

الملف الأساسي: **`reading-library.csv`** — افتحه أو استورده مباشرة في Google Sheets.

## طريقة الإضافة إلى الشيت (30 ثانية)

1. افتح Google Sheets → **File → Import → Upload** → ارفع `reading-library.csv`.
2. اختر **Insert new sheet(s)** ثم **Separator type: Comma**.
3. سمِّ التبويب: `مكتبة القراءة`.
4. من **Data → Split text to columns** لو ظهر كل السطر في عمود واحد.

> بديل أسرع: افتح CSV في المتصفح، انسخ كل المحتوى، والصقه في الخلية `A1`، ثم `Data → Split text to columns`.

## إعدادات مقترحة داخل الشيت

| الإعداد | التفاصيل |
|---|---|
| اتجاه الورقة | من قائمة الورقة اختر **Right-to-left** |
| عمود «الحالة» | Data → Data validation → قائمة: `لم يُنجز`, `قيد التنفيذ`, `أُنجز`, `مؤجل` |
| تلوين شرطي | `أُنجز` = أخضر، `مؤجل` = أصفر، `لم يُنجز` = رمادي |
| تجميد الصف الأول | View → Freeze → 1 row |
| عمود «الرابط» | Format → Wrapping → Clip حتى لا يتمدد العمود |
| عمود جديد «تاريخ الإنجاز» | يُملأ يدويًا أو بـ `Ctrl+;` |

### نسبة الإنجاز (ضعها في خلية فارغة)

```
=TEXT(COUNTIF(I2:I;"أُنجز")/COUNTA(I2:I);"0%")&" مكتمل"
```

**لماذا؟** معرّفات يوتيوب عشوائية ولا يمكن تخمينها؛ الرابط الخاطئ يعني فيديو محذوف أو غير ذي صلة. الأفضل أن تفتح رابط البحث مرة واحدة وتلصق الرابط النهائي في عمود «الرابط» وتغيّر «حالة الرابط» إلى `مؤكد`.

### إضافات أخرى قمت بها
- عمود **«حالة الرابط»** لتعرف أي رابط يحتاج تأكيدًا.
- عمود **«الفترة» + «الوقت»** منفصلين ليسهل الفرز والتصفية.
- توزيع وقتي: المادتان الصباحيتان 7:00 و7:20 بدل تكديسهما في نفس الدقيقة (26 دقيقة إجمالًا).
- بند خامس مسائي **«مراجعة اليوم»** لإغلاق الحلقة — احذفه إن لم يناسبك.
- ضبط صياغة الأسئلة لغويًا (غدًا، الخطوة الواحدة…) وإكمال السؤال الثالث للمادة الرابعة الذي كان مقطوعًا.
