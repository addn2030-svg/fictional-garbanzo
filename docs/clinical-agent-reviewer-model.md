# نموذج وكيل المراجعة السريرية (Howsawy Reviewer)

**الغرض:** تلخيص تنفيذ الوكيل الحالي، ثم اقتراح نموذج ذكاء اصطناعي يراجع التنفيذ ويُعيد توجيه التوصيات وفق خمس تقنيات فقط:

1. **NKT** — NeuroKinetic Therapy  
2. **ANF** — Amino Neuro Frequency Therapy  
3. **Myofascial** — تحرير اللفافة العضلية  
4. **Dry Needling** — الوخز الجاف  
5. **Manual Therapy** — العلاج اليدوي  

**الحالة المرجعية:** Frozen Shoulder أيسر — مرحلة الذوبان (Stage 3 / Thawing)  
**صيغة المخرجات:** SOAP (Subjective / Objective / Assessment / Plan)  
**مستوى الاستخدام:** Clinical Decision Support فقط — القرار النهائي للممارس.

---

## 1) ملخص تنفيذ الوكيل الحالي

### ماذا فعل الوكيل (Howsawy)؟

الوكيل أنتج دعم قرار سريري ثم SOAP لنفس الحالة. التحليل السريري كان منطقياً في جزء التصنيف (thawing) وفحص الأعلام الحمراء، لكن **خطة العلاج خرجت عن حزمة التقنيات المعتمدة**.

| المحور | ما نفّذه الوكيل | الحكم |
|---|---|---|
| التصنيف المرحلي | Stage 3 Thawing (ألم 2/10، تحسن تدريجي، تيبس متبقٍ) | مقبول |
| الأعلام الحمراء | عنق، كفة مدورة، صدرية، سكري/درقية، عصبي | مقبول كقائمة فحص |
| القياس | Flexion/Abd ~80°، IR 10°، ER 15°، صدرية محدودة | مقبول |
| الاستجابة للجلسة | تحسن الانثناء إلى ضمن 5°–8° من الجانب السليم | مقبول |
| الخطة العلاجية | Maitland glides، Mulligan MWM، PA صدري، scapular setting، Codman | **غير مطابق للحزمة** |
| التوثيق | SOAP موجود لكن الخطة غير مكتملة (IR target مقطوع) | ناقص |

### الفجوة الجوهرية

التنفيذ ركّز على:

- Mulligan MWM  
- Maitland Grade III–IV (inferior / posterior glide)  
- Thoracic PA + lateral flexion overpressure  
- Scapular setting + pendulums  

بينما المطلوب أن تُشتق التوصيات **حصراً** من: NKT / ANF / Myofascial / Dry Needling / Manual Therapy.

### قراءة سريرية مختصرة للحالة (كما وردت)

- **S:** ألم وتيبس كتف أيسر 6 أشهر، تحسن تدريجي، ألم 2/10 مع الحركة فقط، لا ألم راحة.  
- **O:** عنق سليم وعصبي سلبي. نمط محفظي (ER 15° > IR 10° > ABD/Flex ~80°). نقص حركة صدرية (دوران/بسط/انحناء جانبي).  
- **A:** التصاق محفظي أيسر — مرحلة ذوبان، مع مساهمة صدرية ولوحية. استجابة داخل الجلسة ممتازة بعد تحريك صدري/لوحي.  
- **P عند الوكيل:** تقدم MWM وإعادة قياس IR/ER — دون بروتوكول NKT/ANF/DN/MFR.

## 2) النموذج المقترح: وكيل مراجعة التنفيذ

يُقترح وكيل من **ثلاث طبقات** بدل وكيل واحد يخلط التشخيص بالبروتوكول العام.

```
                    ┌──────────────────────────┐
                    │  Layer 0 — Safety Gate   │
                    │  CDS disclaimer + PII    │
                    │  Red flags / consent     │
                    └────────────┬─────────────┘
                                 │
          ┌──────────────────────┼──────────────────────┐
          ▼                      ▼                      ▼
 ┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
 │ Layer 1         │   │ Layer 2         │   │ Layer 3         │
 │ Case Parser     │──▶│ Modality Mapper │──▶│ SOAP Composer   │
 │ SOAP extract    │   │ NKT ANF MFR DN  │   │ Reviewer output │
 │ stage + ROM     │   │ Manual Therapy  │   │ + gap report    │
 └─────────────────┘   └─────────────────┘   └─────────────────┘
```

### الأدوار

| الدور | المسؤولية | لا يفعل |
|---|---|---|
| **Safety Gate** | يمنع التوصية عند علم أحمر غير محسوم؛ يمنع تخزين هوية المريض | لا يشخص بديلاً عن الطبيب |
| **Case Parser** | يستخرج S/O/A من الإملاء أو SOAP السابق | لا يخترع زوايا غير مذكورة |
| **Modality Mapper** | يربط كل موجود سريري بتقنية من الحزمة الخمس فقط | لا يقترح Mulligan/Codman/تمرين عام إلا كـ HEP مكمل داخل Manual/NKT |
| **Reviewer** | يقارن تنفيذ الوكيل السابق بالمعايير ويعيد كتابة الخطة | لا يمدح التنفيذ غير المطابق |

### قواعد توجيه صارمة (Guardrails)

1. كل بند في **Plan** يجب أن يحمل وسماً: `NKT | ANF | MYOFASCIAL | DRY_NEEDLING | MANUAL`.  
2. إن لم تنطبق تقنية: تُذكر صراحةً «غير مستطب في هذه الجلسة» مع السبب.  
3. ممنوع اقتراح تقنيات خارج الحزمة (Mulligan، Maitland كاسم بروتوكول مستقل، Codman، tape، shockwave…) إلا إذا أُعيد تصنيفها تحت Manual Therapy مع تبرير.  
4. Dry Needling و ANF لا يُوصى بهما دون موافقة موثقة وموانع مستبعدة.  
5. المرحلة تحدد الشدة: Thawing = جرعات أعلى للحركة اليدوية + NKT لإعادة البرمجة؛ تجنب الاستفزاز الالتهابي.  
6. المخرجات دائماً SOAP + جدول مطابقة + فجوات التنفيذ السابق.

## 3) خريطة الحالة → التقنيات الخمس

| الموجود | التقنية | الهدف السريري | جرعة مقترحة لهذه الحالة (Thawing) |
|---|---|---|---|
| نمط تعويض لوحي/صدري + تثبيط متوقع لـ lower trap / infraspinatus | **NKT** | كشف المعضّل المسهّل مقابل المثبّط؛ إطلاق دائرة التعويض ثم إعادة برمجة المحرك | اختبار عضلي يدوي → إطلاق النقطة المسهّلة → إعادة اختبار فوري → 10–15 تكرار منزلي للنمط الصحيح |
| حساسية عصبية محيطية/موضعية متبقية رغم ألم 2/10 | **ANF** | تعديل الإشارة الالتهابية والعصبية حول المحفظة والضفيرة والسلسلة الصدرية | أقراص ANF حسب خريطة الكتف/T-spine وفق بروتوكول العيادة؛ مراجعة 48–72 ساعة |
| تيبس لفافي خلفي/إبطي/صدري ولوحي | **Myofascial** | خفض توتر المحفظة الخلفية واللفافة الصدرية والل levator/subscapularis | 3–5 دقائق/منطقة، ضغط مستمر أو تحرير مباشر، تحمل ألم ≤ 4/10 |
| نقاط زناد (subscapularis, infraspinatus, upper trap, pec minor) | **Dry Needling** | خفض الألم الرجيع وتحسين الإرخاء قبل التعبئة اليدوية | 1–2 مناطق/جلسة في الذوبان؛ تجنب العدوانية؛ إعادة تقييم ROM فوري |
| نقص ER/IR/Abd + صدرية ناقصة الحركة | **Manual Therapy** | استعادة انزلاق رأس العضد وحركة T3–T8 دون تسمية بروتوكولات خارج الحزمة | تعبئة محفظية متدرجة + تحريك صدري/لوحي 3×45–60 ث |

**تسلسل الجلسة المقترح (هذه الحالة):**

1. Safety + موافقة (DN/ANF)  
2. **NKT** تقييم دوائر الكتف/اللوح  
3. **Dry Needling** للنقاط المسهّلة المؤكدة (إن استُطب)  
4. **Myofascial** للمحفظة الخلفية واللفافة الإبطية/الصدرية  
5. **Manual Therapy** لتعبئة GH + صدري  
6. **ANF** لتشبيك التهدئة العصبية بين الجلسات  
7. إعادة اختبار NKT + ROM (IR/ER/Flex) وتوثيق SOAP

## 4) مخرج المراجع — SOAP موجّه للحزمة

> Clinical Decision Support Only — القرار النهائي للممارس. لا تُخزَّن هوية المريض.

### S — Subjective

- شكوى: ألم وتيبس كتف أيسر مزمن (6 أشهر) متوافق مع التصاق محفظي.  
- الألم: 2/10 مع الحركة؛ لا ألم راحة.  
- السير: تحسن مقارنةً بـ 3 أشهر؛ التزام بتمارين منزلية.  
- المرحلة الانطباعية: Thawing (Stage 3).

### O — Objective

- عنق: سليم. عصبي: سلبي.  
- ROM أولي أيسر: Flex ~80° / Abd ~80° / IR 10° / ER 15°. نمط محفظي.  
- صدرية: نقص انحناء جانبي + دوران + بسط.  
- بعد تدخل سابق (خارج الحزمة): Flexion وقوف ضمن 5°–8° من الجانب المقابل.  
- لم يُوثَّق بعد: اختبار NKT عضلي، خريطة نقاط الزناد، موانع DN/ANF، خريطة أقراص ANF.

### A — Assessment

- تشخيص أولي: Adhesive capsulitis أيسر — مرحلة ذوبان.  
- محركات قابلة للعلاج داخل الحزمة:  
  - دائرة تعويض حركي (NKT)  
  - تيبس لفافي محفظي/صدري (Myofascial)  
  - نقاط زناد محتملة تُعيق ER/IR (Dry Needling)  
  - نقص انزلاق مفصلي GH + T-spine (Manual Therapy)  
  - بقاء حساسية عصبية منخفضة الدرجة (ANF)  
- الإنذار: جيد (مرحلة 3، استجابة داخل الجلسة، عنق سليم).  
- **مراجعة التنفيذ السابق:** التحليل جيد؛ الخطة غير مطابقة (MWM/Maitland/Codman). يُعاد بناء الـ Plan.

### P — Plan (حصر التقنيات)

| الأولوية | الوسم | التدخل | معيار النجاح للجلسة القادمة |
|---|---|---|---|
| 1 | NKT | تقييم infraspinatus / subscapularis / lower trap / pec minor؛ إطلاق المسهّل ثم إعادة اختبار | اختبار عضلي ينقلب من ضعيف إلى قوي فورياً |
| 2 | DRY_NEEDLING | DN لـ subscapularis و/أو infraspinatus إن وُجدت نقاط زناد وبعد نفي الموانع | انخفاض ألم الحركة + زيادة IR أو ER ≥ 10° |
| 3 | MYOFASCIAL | تحرير المحفظة الخلفية، الإبط، pec minor، لفافة صدرية جانبية | تحمل تمدد أفقي دون حماية عضلية |
| 4 | MANUAL | تعبئة GH باتجاه العجز المحفظي (ER/IR/Abd) + تحريك T3–T8 | ER نحو 30° و IR نحو 25° كهدف مرحلي |
| 5 | ANF | بروتوكول كتف/سلسلة ودّية-صدرية حسب دليل العيادة | استقرار الألم ≤2/10 بين الجلسات |

**منزلية (داخل NKT + Myofascial فقط):** نمط التنشيط الذي نجح في إعادة الاختبار؛ تمدد لفافي قصير يومي بتحمل منخفض.  
**إعادة التقييم:** درجات IR/ER نهاية المدى + إعادة اختبار NKT في الجلسة التالية.

## 5) بطاقة مراجعة التنفيذ (يستخدمها الوكيل آلياً)

| بند المراجعة | وزن | نتيجة التنفيذ السابق |
|---|---|---|
| SOAP مكتمل العناصر | 10% | جزئي (Plan مقطوع) |
| المرحلة السريرية صحيحة | 10% | نعم — Thawing |
| Red flags مذكورة | 10% | نعم |
| كل توصية داخل الحزمة الخمس | 30% | فشل |
| تسلسل منطقي (تقييم → إطلاق → إعادة برمجة → تعبئة) | 15% | غير مطبّق |
| جرعات وموانع DN/ANF | 15% | غائب |
| أهداف ROM قابلة للقياس | 10% | ناقص |

**القرار:** `REJECT_AND_REWRITE` — يُقبل التحليل ويُرفض البروتوكول، ثم تُولد خطة الحزمة أعلاه.

عتبات مقترحة:

- `PASS` ≥ 80 والحزمة مكتملة  
- `REVISE` 50–79  
- `REJECT_AND_REWRITE` < 50 أو أي توصية خارج الحزمة دون إعادة تصنيف

## 6) قالب System Prompt للوكيل المراجع

يُلصق في طبقة النظام للوكيل السريري:

```
You are a clinical physiotherapy reviewer (decision support only).
You never store patient identifiers.

Allowed treatment labels (exclusive):
NKT | ANF | MYOFASCIAL | DRY_NEEDLING | MANUAL

Workflow:
1) Parse the case into SOAP. Do not invent missing ROM/test values; mark them "not documented".
2) Score the incoming plan against the five modalities.
3) If any technique is outside the set, reject that item and replace it with the closest allowed modality, or omit it.
4) Output:
   - SOAP (S/O/A/P)
   - Modality map table
   - Review score + PASS|REVISE|REJECT_AND_REWRITE
   - Session sequence: NKT screen → DN (if indicated) → Myofascial → Manual → ANF
5) Dry needling and ANF require contraindications + consent notes.
6) Final clinical decisions remain with the treating clinician.
Language: match the clinician (Arabic or English). Keep technique names in English.
```

## 7) ماذا يُراجع هذا النموذج في «التنفيذ التالي»؟

عند وصول أي مخرجات وكيل (مثل رد Howsawy السابق) يفحص المراجع:

1. هل الحالة فُكّكت إلى SOAP دون هلوسة أرقام؟  
2. هل الخطة تستخدم التقنيات الخمس فقط؟  
3. هل التسلسل يحترم المنطق العصبي-العضلي (NKT قبل التقوية، DN/MFR قبل التعبئة العدوانية)؟  
4. هل المرحلة (freezing/frozen/thawing) تغيّر الجرعة؟  
5. هل هناك موافقة وموانع لـ DN و ANF؟  
6. هل الأهداف رقمية (ER/IR/Flex) ومرتبطة بإعادة اختبار؟

**خلاصة التوصية:** لا تُستبدل طبقة التشخيص؛ تُضاف طبقة **Reviewer + Modality Mapper** تمنع خروج الوكيل إلى Mulligan/Codman وتعيد كتابة الـ Plan داخل NKT / ANF / Myofascial / Dry Needling / Manual Therapy.
