# سجل القرار — تجميد القدرات وحوكمة الحالة

- **التاريخ:** 2026-09-06
- **الحالة:** مُعتمد (تنفيذًا للقرارات المطلوبة في المراجعة الأسبوعية)
- **الفترة:** 2026-09-06 ← 2026-09-13 (أسبوع تجميد واحد)
- **المرجع:** `reviews/2026-09-06-executive-review.md`

## D1 — تجميد إضافة القدرات (Capability Freeze)

لمدة أسبوع (حتى مساء 13 سبتمبر 2026):

- **لا** فتح أي PR جديد يضيف capability أو Agent أو موصل (connector) جديد.
- يُسمح فقط بـ: إصلاحات FAIL الناتجة عن P0، اختبارات قبول، توثيق، وملفات قياس (P2).
- أي استثناء يتطلب سجل قرار جديد يوضح المبرر وشرط الإنهاء.

## D2 — مصدر حقيقة واحد للحالة

- `ops/capability-register.md` هو **الجدول الوحيد المعتمد** لحالة كل قدرة.
- الحقول إلزامية لكل صف: Capability / Status / Acceptance Test / Owner / Rollback.
- قيم الحالة: **Live** (مُختبر من Telegram ومثبت) · **Canary** (مدمج بعلم/flag مطفأ) · **Shadow** (يعمل دون أثر إنتاجي) · **Draft** (PR مفتوح غير مدموج) · **Not-in-main** (PR مغلق غير مدموج أو كود غير موجود).
- أي ادعاء في مراجعة أو وثيقة يتعارض مع الجدول يُصحَّح لصالح الجدول، والجدول يُصحَّح لصالح GitHub + سجلات التشغيل (راجع `fact-check-2026-09-06.md`).

## D3 — Commerce يبقى في حدود Pilot

- السقوف الصلبة تبقى كما هي: **375 ريال/طلب، 375 ريال/يوم** (مؤكدة في الكود: `PILOT_MAX_ORDER_SAR` / `PILOT_MAX_DAILY_SAR`).
- لا توسعة للصلاحيات المالية، ولا رفع للسقوف، ولا إضافة فئات شراء جديدة حتى توجد بيانات استخدام حقيقية (عدد طلبات، نسب موافقة/رفض، إيصالات فعلية) تُراجَع في المراجعة الأسبوعية التالية.

## D4 — لا تفعيل تلقائي لـ Strategic Creator أو المدير النشط متعدد الوكلاء

- يبقى كلاهما خارج المسار الإنتاجي حتى تغلق اختبارات Core Manager (P0) بنتيجة PASS كاملة.
- ملاحظة تحققية: Strategic Creator وActive Multi-AI Manager v0.5 لم يصلا إلى `main` أصلًا (PR #75 و#13 مغلقان بدون دمج — راجع fact-check). القرار حاليًا هو **عدم إعادة تقديمهما للدمج** قبل P0 وليس فقط عدم التفعيل.
- تمييز مهم: **بوابة النماذج الموحدة (OpenRouter + سقوط Bedrock) مدموجة فعلًا** في `connectors/model_gateway.py` وتخدم `/council` الحالي — هذه ليست "AI Council الجديد" ولا تشمل الأوركسترا التلقائية. لا تغيير عليها في هذا القرار.

## شرط رفع التجميد

يرفع التجميد في مراجعة 13 سبتمبر فقط إذا:
1. كل أسطر P0 في `p0-production-truth-test.md` نتيجتها PASS (أو FAIL موثق بمسار إصلاح مغلق).
2. اختبار P1 للذاكرة موثق بنتيجة PASS مع دليل 0 writes.
3. بطاقة قياس P2 تحتوي بيانات أسبوع حقيقية ولو بأثر رجعي.
